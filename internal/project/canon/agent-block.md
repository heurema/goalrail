## Goalrail project flow

This repository is managed by the committed `.goalrail/project.json` declaration. Before any material code or governing-document change, read and follow `.goalrail/bootstrap.md`; it is the canonical setup, intent, lineage, and admission protocol for every supported agent.

Inspect project and local readiness read-only. If compatible Goalrail tooling or the selected attachment is absent, report `GOALRAIL_SETUP_REQUIRED`, make zero project-code writes, and follow the canonical exact-plan authorization and receipt flow. Do not initialize an already declared clone, substitute provider-local policy, or continue the feature request before the bootstrap protocol permits it.
